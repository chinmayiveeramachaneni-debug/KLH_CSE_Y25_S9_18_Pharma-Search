# Pharma Search

## Project Overview

Pharma Search is a medicine information search system developed using Data Structures and Algorithms. The project helps users quickly search for medicine information and retrieve important details in an organized manner.

The system allows users to search for medicines by name and view information such as composition, manufacturer, dosage, uses, availability, and alternative medicines.

## Features

- Searches medicines by name
- Displays medicine composition
- Displays manufacturer information
- Displays dosage information
- Displays medicine uses
- Checks medicine availability
- Finds alternative medicines
- Stores medicine records in a structured format
- Uses searching algorithms for medicine retrieval
- Uses Data Structures for efficient data organization
- Provides fast access to medicine information
